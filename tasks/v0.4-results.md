By Hla.Sh · 20 November 2026 · 0.4.0-alpha.1

Scope followed the approved brief: refactor (no rewrite), local service kept, speed + solidity + accuracy. The Chrome extension, publishing, re-import and prototypes are out of scope.

## Measured results

All public captures used the local CLI on this machine; times are wall-clock for the full capture. "Editor payload" is the compact JSON the plugin receives (screenshots omitted).

## Native Figma check

File: [Website to Figma v0.4 native check](https://www.figma.com/design/xS4jsQjETMiSJp5VoVUZDv) (Newteam Drafts).

The exact paints, effects, borders and transforms that the renderer computes for an owned test page were applied through the Plugin API and compared side by side with the browser screenshot of the same capture. Figma accepted all of them without errors and matched the browser for: linear (side and angle), radial and conic gradients; inset plus drop shadow; layer blur; a positioned `::before` bar; 30° rotation (direction and centre); uppercase text case; text shadow; gradient-clipped text.

Difference found: Figma dashes were sparser than Chrome's. The renderer now uses a `[2w, w]` dash pattern; this tweak was **not re-checked natively** because of the call limit. A stray dash setting was applied to the conic test box in that file; it has no visible effect (the box has no stroke).

This check exercised the new paint code paths, not a full end-to-end import through the installed plugin. The full renderer bundle plus a scene is ~48 KB, at the MCP script limit.

## What changed

Speed
- Original JPEG/PNG/GIF bytes are kept; only other formats, EXIF-rotated or >4096 px images are re-encoded (JPEG when opaque, PNG when transparent).
- Font check sends only the font list; the editor fetches the scene without screenshots (`?screenshots=0`); the scene is validated once in the main thread.
- Native `figma.base64Decode`, fast UTF-8 SVG decoding, layout derivation cached per node, renderer yields to the event loop.
- Widths are captured in parallel pages of one browser.
- Shipped `code.js` dropped from 112 KB to 65 KB (no embedded UI copy, no test code).

Solidity
- Request and image-byte limits skip extra downloads instead of aborting the capture.
- Over-budget or deeply nested regions become measured images (`raster-fallback`) instead of failing.
- Pages that keep moving are frozen (animations finished or paused, timers, frames, idle callbacks and new animations stopped); the capture keeps a private timer.
- Media-frame screenshots run after the change check; screenshot-only drift is a warning, not a retry.
- Fixed: the last retry discarded its own image assets.
- Shipped build excludes verification hooks, telemetry and the Amazon special cases; `dist/diagnostic` keeps them for acceptance runs and `install-local --verify-*` installs that build.

Accuracy
- Gradients: linear, radial, conic, multiple layers, overlays above background photos, gradient text.
- Borders per side, dashed and dotted.
- Multiple and inset box shadows, text shadow, blur and backdrop blur.
- `::before`/`::after`: positioned boxes become layers; inline strings (labels, arrows, icon glyphs) join the text, including on inline descendants.
- Leaf layers keep CSS rotation natively.
- Text keeps authored characters and uses Figma text case.
- Variable names are readable (`color/#1a334d`, `space/10`); padding is bound once, so no unused variables.

## Real import test: two Arabic stores (20 November 2026)

Both sites were imported through the installed plugin in Figma Desktop (Desktop + Mobile, 1440 and 390) into [Website to Figma v0.4 native check](https://www.figma.com/design/xS4jsQjETMiSJp5VoVUZDv): page "Superstarsy" (superstarsy.com/ar) and page "Puzzle Store" (puzzlestore.vercel.app). Earlier test imports were moved to the page "Archive / first import", not deleted.

Found and fixed during the test:

| Problem seen in Figma | Fix |
| --- | --- |
| Layers named after Tailwind classes (`flex`, `w-4`, `mx-auto`, `__variable_1f41d9`) | Naming pass: role and content names (Header, Navigation, Card / title, Link / label, Icon, Grid, Section / heading); author labels and descriptive classes kept |
| Arabic rows lost auto layout (32 of 54 rows at 1440 became fixed positions) | RTL rows and grids are stored in visual order with flipped justification; fixed frames on Superstarsy dropped from 35 to 0 at 1440 |
| Product grid fixed because of an empty `col-span-full` sentinel | Hidden or empty items are ignored by the grid check |
| Short last row of an RTL grid jumped to the left | Measured cells are placed explicitly (manual grid positions), also after component replacement |
| Page container fixed because the sticky header has a z-index | Stacking differences between non-overlapping flow items keep auto layout |
| One-line labels wrapped ("الرئي سية") because Figma's Cairo is slightly wider | Single-line text, buttons and chips hug their copy |
| Import stopped for "Font Awesome 6 Brands" | Icon-font glyphs become 4× icon images |
| Screens nested inside a plain frame | Screens are top-level frames inside one section named after the site |

Verified: `npm run check` 75 unit/API + 52 Chromium tests, 0 failures; both imports completed in the Desktop app and were inspected on canvas. The one blank product photo on Puzzle Store is a broken image on the site itself (`/Images/s1.jpg` returns 404). Superstarsy's coloured collection tiles are the site's own solid-colour images.

Still open: one Superstarsy page load timed out at the 20 s navigation limit on a slow moment (a retry worked); spacing frames named "Spacing / source margin" remain where browser margins are uneven; each import adds its own text styles and variable collection.
